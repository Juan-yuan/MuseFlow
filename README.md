# MuseFlow
- An AI-powered content creation and publishing workflow built with LangGraph.
- MuseFlow automates the entire content lifecycle, from idea generation and AI writing to image generation, content review, and publishing.

## Features
- AI-powered content generation
- AI image generation
- LangGraph-based agent orchestration
- Automated content publishing
- Human-in-the-loop review and approval
- Extensible workflows for multiple social media platforms

## Tech Stack
- Python
- LangGraph
- LangChain
- LLMs
- Image Generation APIs
